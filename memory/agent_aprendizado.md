# Aprendizado do Agente

Este arquivo deve registrar apenas melhorias aprovadas.

## Regras
- não registrar conteúdo bruto de conversas
- não registrar dados pessoais identificáveis
- registrar apenas padrões úteis e revisados

## Exemplo de registro
- Clientes costumam responder medida e orçamento na mesma mensagem; quando isso acontecer, evitar repetir a pergunta de orçamento.
